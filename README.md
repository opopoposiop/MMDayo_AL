# PPAL — Post-Process AutoLuminous

PPAL は、[MikuMikuDayo](https://github.com/pennennennennennenem/MikuMikuDayo) 用の [AutoLuminous](https://www.nicovideo.jp/watch/sm16087751) ぽいポストプロセスです。  
モデルの材質または追加 UV から発光色を抽出し、タイトブルーム、ワイドブルーム、星形グレアを元の画面へ加算合成します。

## ファイル

- `PPAL_2.fxdayo` — AutoLuminous ぽいポストプロセス本体
- `PPAL_2.pmx` — エフェクトを操作するコントローラーモデル

## 導入方法

1. `PPAL_2.fxdayo` と `PPAL_2.pmx` を同じフォルダーに置きます。
2. MikuMikuDayo で `PPAL_2.pmx` を読み込みます。
3. `PPAL_2.pmx` のモーフで発光やぼかしなどを調整します。

## コントローラーモーフ

`PPAL_2.pmx` には次の9個のモーフがあります。

| モーフ | 内容 | 値の目安 |
|---|---|---|
| `off` | エフェクトの消灯 | `0` = 全開、`1` = 消灯 |
| `発光強度` | Si方式の発光強度 | `0` = 標準（×1）、`-1` = 消灯、`+1` = ×2 |
| `ぼかし幅低減` | ぼかし幅の低減 | `0` = 最大、`1` = 最小 |
| `光芒数` | 光芒の方向数 | `0`～`9`。`0`では光芒なし |
| `元画面輝度` | 元画面の輝度 | `0` = 変化なし、`-100` = 完全な黒、`+100` = ×2 |
| `AL-Z発光強度` | AL-Z規格の発光強度 | `-100`～`500` |
| `光芒角度` | 光芒全体の回転角度 | 度単位 |
| `光芒長さ` | 光芒の長さ | `-100` = 長さ0、`0` = 標準、`+100` = ×2 |
| `点滅周期` | 発光全体の点滅周期 | 秒単位。正値 = 滑らかな波、負値 = 矩形波、`0` = 停止 |

発光強度には `発光強度` と `AL-Z発光強度` の両方が掛かります。計算上の倍率は次のとおりです。

```text
発光倍率 = max(0, 1 + 発光強度) × max(0, (100 + AL-Z発光強度) / 100) × saturate(1 - off) × 点滅倍率
```

`ぼかし幅低減`はぼかしを弱くする方向にだけ働きます。値を大きくするとタイト層とワイド層の両方が細くなります。

`光芒数`に`N`を指定すると、N方向の各正逆方向へ伸びる光芒が生成されます。内部では値を整数へ丸め、`0`～`9`の範囲に制限します。

`点滅周期`が正の場合、AutoLuminous互換のため発光倍率は約`0.2`～`1.0`の範囲で滑らかに変化します。負の場合は点灯と消灯を交互に切り替えます。

## 発光材質の設定

PPAL は次の2方式で発光箇所を判定します。

### 方式A：材質指定

発光させる材質を次のように設定します。

- スペキュラ色：黒 `(0, 0, 0)`
- Shininess（反射強度）：`100` 以上

Shininess が高いほど発光が強くなり、材質の拡散色、環境色、テクスチャ色を基に発光色を作ります。内部の最大オーバーブライト値は `16` です。

### 方式B：追加UV指定

発光させる頂点の追加 UV1 の XY を、およそ `(0.2, 0.7)` に設定します。

方式Bでは、追加 UV に格納された色、強度、テクスチャ利用方法、点滅周期などの情報を使って頂点単位の発光を計算します。HSV カラーモードにも対応しています。

## エフェクトの処理

PPAL は次の順に画面を処理します。

1. `EmissiveExtract` — 発光色を抽出
2. `BloomBlurH` / `BloomBlurV` — 近接するタイトブルームを生成
3. `BloomBlurH_Wide` / `BloomBlurV_Wide` — 広範囲のワイドブルームを生成
4. `Glare` — タイトブルームから星形グレアを生成
5. `BloomComposite` — 元画面へタイト、ワイド、グレアの3層を加算合成

`元画面輝度`はブルームの強さではなく、合成前の元画面の明るさを調整します。

## 内部設定

| 項目 | 値 |
|---|---:|
| タイトブルーム強度 | `1.20` |
| タイトブルーム σ | `5.0` |
| タイトブルーム半径 | `9` |
| ワイドブルーム強度 | `0.60` |
| ワイドブルーム σ | `20.0` |
| ワイドブルーム半径 | `24` |
| グレア強度 | `0.50` |
| グレアステップ数 | `16` |
| グレアステップ幅 | `8.0` |
| グレア減衰 | `0.15` |

## 注意事項

- 本エフェクトは MikuMikuDayo の YRZFX ポストプロセスです。
- `PPAL_2.fxdayo` のコントローラー定義は、`PPAL_2.pmx` 自身の同名モーフを参照します。
- Radeon 環境を考慮し、bindless テクスチャの添字には `NonUniformResourceIndex` を使用しています。
- モーフ欄の通常のスライダー範囲を超える値は、必要に応じて数値入力してください。
