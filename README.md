# PPAL — Bloom/Glare Post-Process for MikuMikuDayo

PPAL は、[MikuMikuDayo](https://github.com/pennennennennennenem/MikuMikuDayo) 向けの発光ポストプロセスです。
モデルの材質または追加UVから発光色を抽出し、タイトブルーム、ワイドブルーム、星形グレアを元の画面へ加算合成します。

本プロジェクトは [AutoLuminous](https://www.nicovideo.jp/watch/sm16087751) ぽい動作をする独立実装です。AutoLuminousの公式版・移植版ではありません。

## ファイル

- `PPAL_2.fxdayo` — 発光抽出、ブルーム、グレア、合成を行うポストプロセス本体
- `PPAL_2.pmx` — エフェクトを操作するコントローラーモデル
- `archive/` — 旧版 `PPAL.pmx` / `PPAL.fxdayo`

## 動作要件

- MikuMikuDayo の YRZFX ポストプロセス環境
- HLSLシェーダーを実行できるMikuMikuDayoの対応GPU環境
- MME / MikuMikuDance用 `.fx` との互換性はありません

シェーダーはMikuMikuDayo側の `resources_pp.hlsli` と `yrz.hlsli` を参照します。これらの依存ファイルは本リポジトリには含まれていません。利用するMikuMikuDayoの配布物・バージョンでYRZFXポストプロセスが利用できることを確認してください。

## 導入方法

1. `PPAL_2.fxdayo` と `PPAL_2.pmx` を同じフォルダーに置きます。
2. MikuMikuDayo で `PPAL_2.pmx` を読み込みます。
3. `PPAL_2.pmx` のモーフで発光やぼかしなどを調整します。

## コントローラーモーフ

`PPAL_2.pmx` には次の9個のモーフがあります。

| モーフ | 内容 | 値の目安 |
|---|---|---|
| `off` | エフェクトの消灯 | `0` = 全開、`1` = 消灯 |
| `発光強度` | 材質指定方式の発光強度 | `0` = 標準（×1）、`-1` = 消灯、`+1` = ×2 |
| `ぼかし幅低減` | ぼかし幅の低減 | `0` = 最大、`1` = 最小 |
| `光芒数` | 光芒の方向数 | `0`～`9`。`0`では光芒なし |
| `元画面輝度` | 元画面の輝度 | `0` = 変化なし、`-100` = 完全な黒、`+100` = ×2 |
| `AL-Z発光強度` | AL-Z形式の発光係数 | `-100`～`500` |
| `光芒角度` | 光芒全体の回転角度 | 度単位 |
| `光芒長さ` | 光芒の長さ | `-100` = 長さ0、`0` = 標準、`+100` = ×2 |
| `点滅周期` | 発光全体の点滅周期 | 秒単位。正値 = 滑らかな波、負値 = 矩形波、`0` = 停止 |

発光強度には `発光強度` と `AL-Z発光強度` の両方が掛かります。計算上の倍率は次のとおりです。

```text
発光倍率 = max(0, 1 + 発光強度) × max(0, (100 + AL-Z発光強度) / 100) × saturate(1 - off) × 点滅倍率
```

`ぼかし幅低減`はぼかしを弱くする方向にだけ働きます。値を大きくするとタイト層とワイド層の両方が細くなります。

`光芒数`に`N`を指定すると、N方向の各正逆方向へ伸びる光芒が生成されます。内部では値を整数へ丸め、`0`～`9`の範囲に制限します。

`点滅周期`が正の場合、発光倍率は約`0.2`～`1.0`の範囲で滑らかに変化します。負の場合は点灯と消灯を交互に切り替えます。

## 発光材質の設定

PPAL は次の2方式で発光箇所を判定します。

### 方式A：材質指定

発光させる材質を次のように設定します。

- スペキュラ色：黒 `(0, 0, 0)`
- Shininess（光沢度）：`100` より大きい値

Shininessが`100`を超えると発光し、値が高いほど発光が強くなります。材質の拡散色、環境色、テクスチャ色を基に発光色を作ります。内部の最大オーバーブライト値は`16`です。

### 方式B：追加UV指定

発光させる頂点の追加UV1のXYを、およそ`(0.2, 0.7)`に設定します。

方式Bでは、追加UVに格納された色、強度、テクスチャ利用方法、点滅周期などの情報を使って頂点単位の発光を計算します。HSVカラーモードにも対応しています。

実装上の追加UV値は次のとおりです。

| 値 | 内容 |
|---|---|
| `exuv1.xy` | 発光頂点の識別値。`(0.2, 0.7)`付近で方式Bを有効化 |
| `exuv1.z` | 頂点単位の点滅周期。秒単位。`0`で点滅なし |
| `exuv1.w` | フラグ。1の位がテクスチャモード、10の位が色モード |
| `exuv2.xyz` | 発光色。色モード`1`ではHSVとして扱う |
| `exuv2.w` | 発光強度。`0`～`16`に制限 |
| `exuv3.x` | テクスチャ利用率。テクスチャモード`0`で使用 |
| `exuv3.y` | 頂点単位の点滅位相 |
| `exuv3.z` | `0.5`より大きい場合、頂点単位の点滅を常時点灯へ上書き |

テクスチャモード`0`はテクスチャ色を乗算し、テクスチャモード`2`はテクスチャの輝度から発光量を求めます。

## エフェクトの処理

PPAL は次の順に画面を処理します。

1. `EmissiveExtract` — 発光色を抽出
2. `BloomBlurH` / `BloomBlurV` — 近接するタイトブルームを生成
3. `BloomBlurH_Wide` / `BloomBlurV_Wide` — 広範囲のワイドブルームを生成
4. `Glare` — タイトブルームから星形グレアを生成
5. `BloomComposite` — 元画面へタイト、ワイド、グレアを加算合成し、ワイド層のコアを補正

`元画面輝度`はブルームの強さではなく、合成前の元画面の明るさを調整します。

## 内部設定

| 項目 | 値 |
|---|---:|
| タイトブルーム強度 | `1.20` |
| タイトブルーム σ | `5.0` |
| タイトブルーム半径 | `9` |
| ワイドブルーム強度 | `0.60` |
| ワイドブルーム σ | `20.0` |
| ワイドブルーム半径 | `24` |
| グレア強度 | `0.50` |
| グレアステップ数 | `16` |
| グレアステップ幅 | `8.0` |
| グレア減衰 | `0.15` |

## 注意事項

- 本エフェクトはMikuMikuDayoのYRZFXポストプロセスです。
- `PPAL_2.fxdayo` のコントローラー定義は、`PPAL_2.pmx` 自身の同名モーフを参照します。
- Radeon環境でのリソース参照を考慮し、bindlessテクスチャの添字には `NonUniformResourceIndex` を使用しています。Radeonでの動作は未検証です。
- モーフ欄の通常のスライダー範囲を超える値は、必要に応じて数値入力してください。

## 既知の制限

- MikuMikuDayo本体のバージョンやレンダラー実装により、表示結果や利用できるパラメータが変わる場合があります。
- 本リポジトリには自動コンパイルテストを用意していません。利用するMikuMikuDayo環境で、シェーダーの読み込みと代表的な発光材質を確認してください。
- `archive/`の旧版と`PPAL_2`はモーフ構成が異なります。旧版から更新する場合は、旧PMXを置き換えてください。
